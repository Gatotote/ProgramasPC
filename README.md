# ProgramasPC

Programas de escritorio para Linux hechos por Genaro Velasco. Cada uno vive en su
subcarpeta con su propio `README`/`LEEME`, su `.venv` y su lanzador.

| Carpeta | Qué hace |
|---|---|
| `GPUStressCPU/` | Pruebas de estrés y benchmark (CPU, GPU, RAM, disco, video 4K, escenas 3D) |
| `Organizador/` | Separa el contenido de una carpeta en subcarpetas por tipo |
| `DescargadorYConversor/` | Descarga y convierte video/audio (yt-dlp + ffmpeg) |
| `VaultX/` | VaultX (antes BóvedaFacial): bóveda cifrada con desbloqueo facial + PIN + frase de recuperación |
| `GeniusIQ/` | Estimación casera del CI (estilo WAIS-IV, WISC-V, Stanford-Binet 5, Cattell), personalidad (Big Five, HEXACO, 16 tipos, Eneagrama, perfil laboral, valores) y tamizaje de salud mental (PHQ-9, GAD-7, ASRS, AUDIT, PCL-5), con historial |

El historial de cada programa se conserva: se integró con *subtree merge*
(`git log -- <carpeta>/` o `git log --all` muestran los commits originales).
Solo local, sin remoto.
